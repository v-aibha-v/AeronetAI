Dataset manifest schema

`dataset/manifest.json` is generated by `dataset_prep.py` and records
what the bundled dataset contains.

- `project`: project name.
- `dataset`: the raw dataset directory (`dataset/raw`).
- `generated_at`: manifest creation timestamp in UTC.
- `classes`: the class list (`bird`, `drone`).
- `counts`: source image totals, valid counts, annotation preview
  totals, per-class counts, and total bytes.
- `duplicate_groups`: lists of near-identical source images grouped by
  average-hash distance.
- `annotation_preview_check`: verification that preview files are tiny
  raster previews with no bounding-box geometry.
- `preparation_status`: notes that labels are image-level class labels
  only, with no detection bounding boxes.
