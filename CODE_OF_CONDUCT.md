# Code of Conduct

AeroNet AI is a small, community-friendly open source project. We aim to keep
contributions friendly, inclusive, and useful.

## Our standards

- Be respectful and civil in all communication.
- Give context when proposing changes; explain why a change is useful.
- Critique ideas, not people.
- Assume good intent, and ask for clarification when something is unclear.

## Unacceptable behavior

- Harassment, insults, or discrimination of any kind.
- Deliberately breaking the application or tests.
- Frivolous or spammy issues and pull requests.
- Sharing secrets, credentials, or personal data.

## Scope

This code of conduct applies to the repository, issue trackers, pull request
discussions, and other official project spaces.

## Reporting

If you experience or witness unacceptable behavior, please open an issue or
contact a maintainer. All reports will be reviewed and handled
confidentially.
